## **Git Helper CLI**


`Git Helper CLI` adalah alat bantu berbasis terminal yang mempermudah penggunaan perintah Git sehari-hari, baik untuk kerja individu maupun kolaborasi tim. Dibuat dengan Python, tool ini menyajikan antarmuka interaktif untuk menjalankan perintah Git tanpa perlu mengingat sintaks rumit.

**Fitur Utama:**

* Menampilkan menu perintah Git yang umum digunakan
* Warna-warna terminal untuk tampilan lebih jelas dan nyaman
* Menangani operasi dasar: branch, commit, push, pull, merge, rebase, stash, log, dan lainnya
* Mendukung tampilan grafis commit (`git log --graph`)
* Opsi untuk keluar dan kembali ke menu
* Menampilkan informasi channel YouTube & sosial media
* Bisa diakses dari terminal mana saja via `symlink` CLI (contoh: `git-helper`, `mygit`)

**Instalasi:**

1. Clone repo ini:

   ```bash
   git clone https://github.com/Gopartner/git-helper-termux.git
   cd git-helper-termux
   ```

2. Jalankan script setup:

   ```bash
   bash setup.sh
   ```

3. Masukkan nama CLI sesuai keinginan, misalnya:

   ```
   Masukkan nama CLI: git-helper
   ```

4. Sekarang kamu bisa panggil CLI dari mana saja:

   ```bash
   git-helper
   ```

**Contoh Penggunaan:**

```bash
git-helper
```

Lalu pilih nomor perintah Git yang ingin dijalankan.
